01 / Why Now

為什麼是現在

AI Agent 的信任問題，不能只靠更好的回答來解決。

當 Agent 代表人查詢、下單、送件或簽署時，關鍵不只是答案正確，而是能否說清楚誰授權、做了什麼、何時失效，以及事後如何追溯。

它代表誰？ 被授權做什麼？ 授權何時失效？ 哪些動作需人類確認？ 出事後如何追溯？

06 / Tracks

主題參考方向

四個方向。或走你自己的。

01 供應鏈與貿易金融讓採購 Agent 可驗證、可授權、不可越權付款。
場景痛點
供應商資格、訂單融資、ESG／碳資料可信度。
核心可信問題
Agent 代表買方或法人到什麼程度？能否讀取資格並草擬訂單，但不能自行付款？
示例 POC
供應商資格 VC、訂單到融資證明、ESG 選擇性揭露、採購 Agent 授權。
02 電商與第三方支付代購與支付之間，放一道人類確認。
場景痛點
高頻委託購買、付款授權、防詐與資格驗證。
核心可信問題
Agent 是否只能比價與建立付款意圖？何時必須由使用者確認？
示例 POC
Agent 購買授權、商家信任驗證、年齡／資格選擇性揭露、付款前 human approval。
03 醫療保險敏感資料誰能讀？同意如何被證明？
場景痛點
高度敏感個資、理賠、同意與核保稽核。
核心可信問題
Agent 可讀取哪些醫療資料？是否有有效 consent？送件前如何確認？
示例 POC
可信理賠資料交換、consent VC、隱私保護聯合分析、AI 核保 action log。
04 政府服務代辦到哪一步，由授權說了算。
場景痛點
公部門憑證、跨機關流程、委託送件與國際互認。
核心可信問題
Agent 可以代填、代查或代送到何種程度？哪些動作需本人確認？
示例 POC
公部門憑證升級 VC、Agent 代辦申請、資格驗證、跨境互認概念。

信任要點

作品不必做到產品級；重點是讓評審看懂 Agent 代表誰、被允許做什麼、高風險動作是否受控，以及行為是否可追溯、授權是否可撤銷。

Principal

代表誰？Agent 代表哪一個人、團隊、法人或公部門單位。

Authorization

被授權做什麼？誰授權、允許做什麼、禁止做什麼。

Tool / Action

能呼叫什麼工具？每個工具需要哪些權限與邊界。

Policy Gate

高風險動作如何被擋？付款、送件、簽署或讀取敏感資料需明確把關。

Audit Log

如何追溯行動？記錄 Agent 的行動、決策與授權依據。

Expiry / Revocation

何時失效或撤銷？授權過期或撤銷後，Agent 必須停止執行。

這 6 個要點是協助說明可信設計的參考面向；治理／信任設計說明（Governance Gap Memo）為正式交件項目。

以一頁治理／信任設計說明（Governance Gap Memo），說明作品如何回應這些信任要點。

13 / FAQ

常見問答

單人報名、組隊媒合、出席與交件，一次說清楚。

A. 報名與資格

這場活動是免費的嗎？

完全免費。線下工作坊與活動期間提供餐食。

誰可以參加？

年滿 18 歲，對 AI、軟體開發、設計、產品、資安、數位身份或相關領域有興趣之學生、社會人士與業界人士。

有年齡限制嗎？

有，本活動限年滿 18 歲（報名時全體成員均須年滿 18 歲）。

每隊幾人？

最終每隊 3–5 人，每位參賽者僅能加入一隊；報名時不要求已完成組隊，個人或未滿員隊伍也能先提交。

可以個人報名嗎？

可以。個人、未滿員隊伍與完整 3–5 人隊伍都能報名；個人報名者由本人填寫報名表並作為聯絡窗口。若入選，須在活動前完成 3–5 人隊伍。

個人報名後，如何完成組隊？

報名後可先在團隊媒合平台介紹專長與尋找夥伴。若入選，兩場賽前工作坊都會提供媒合協助；建議個人與未滿員隊伍參與，以便認識隊友、討論分工，並確認最終 3–5 人名單。

怎麼報名？

於報名期間填寫線上報名表：7/8 開放、8/5 截止，由 Team Leader（團隊代表）代表提交，每隊僅提交一次；個人報名者以本人為聯絡窗口。

報名要準備什麼？

團隊背景（建議整理為一份 PDF：成員與角色分工、所屬單位、相關經驗）、想解決的痛點、初步解法構想，以及 GitHub 或作品連結（選填）。個人報名者，團隊背景可改填個人背景與專長。

B. 主題與技術

有指定題目或賽道嗎？

沒有硬性賽道。題目開放自由發想；供應鏈與貿易金融、電商與第三方支付、醫療保險、政府服務只是參考方向，也歡迎其他領域。

技術或框架有限制嗎？

技術自由，但作品須能展示可信 AI Agent 的身份、授權、行動邊界、稽核與撤銷思考，且僅能使用合法授權之模型、資料與工具。

可信 AI Agent 建議展示什麼？

代表誰（Principal）、被授權做什麼（Authorization）、可呼叫的工具與動作（Tool / Action）、政策關卡（Policy Gate）、稽核軌跡（Audit Log）、失效與撤銷（Expiry / Revocation）。

一定要用區塊鏈或數位憑證（VC）嗎？

不強制。只要能清楚展示身份、授權、驗證、稽核與撤銷即可；區塊鏈／VC 是選項而非必需。

需要自備設備嗎？

請自備筆電及開發所需個人裝置；現場提供網路、電力與活動期間餐食。
